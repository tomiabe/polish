# Visual rhythm regression fixture

This pair turns recurring UI craft feedback into a compact review fixture. It is intentionally product-neutral.

- The before version leaves a menu glyph to browser button layout, so its visual centring is not explicit.
- It shows two controls for the same close action in the mobile navigation.
- It relies on fieldset defaults, leaving the next filter group without deliberate spacing.
- Its hero is constrained by the page shell, even though the design calls for a full-bleed surface.

The after version makes the layout intent explicit. Run Polish with both the HTML and CSS files, and attach desktop or mobile screenshots when checking the rendered result.
