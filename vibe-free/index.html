The seven tells

0 of 7 found
That is exactly what the contract is for. See the eight rules

Eight rules, one file.

The full contract lives in AGENTS.md. Each rule carries the resource the model gets pointed at.

0 Visual direction comes first

Before any code, write one paragraph: where the palette comes from, the dominant accent, the texture and personality, and three things this will not look like. Read it back before every screen. Generic output is the default. Specificity is the only known fix.

1 Design contract

One accent, two typefaces, one spacing scale, one radius set, one icon family. Pull the palette from the identity. Build on a named component system instead of hand-rolling what it already gives you.

shadcn/ui Phosphor Icons Aria Icons
2 Structure and composition

No default hero plus three feature cards unless the content demands it. Real content only: real names, real numbers, real screenshots. Give the page an order to be read in and vary the shape of every section.

3 Motion

150 to 250ms, eased, purposeful. Animate on state change and scroll reveal, never on every element. Motion clarifies, it does not decorate. Easy scroll, and respect reduced motion.

Transitions.dev beUI Emil Kowalski skill
4 Sound

Confirmations and completions only. Routine interactions stay silent. Overused sound reads as gimmicky, which is where the thread landed on it too.

Cuelume
5 Copy

Cut the signs of AI writing, the superlative stacks, and the throat-clearing intros. No em dashes or en dashes, nothing in italics for emphasis, no eyebrow labels. Cut 20 percent at the end. Shorter reads more human.

Signs of AI writing
6 Responsive

Check at 375, 768, and 1280 before anything is called done. Navigation, tables, dense sections, forms, and the footer all count, not only the hero.

7 Review loop, not a final gate

Audit after structure, after the visual pass, after the copy pass. Then run polish against the code, the copy, and the screens, and fix what it flags before shipping.

Where it earns its keep

Same contract, different surfaces.

Landing pages

The first screen everyone judges. One accent, real copy, motion that explains. The gradient hero has nowhere to hide once the visual direction paragraph is written first.

hero / pricing / waitlist

Client work

Start every project from the same file, so a week of client work still looks like one person made deliberate decisions. The contract is the deliverable before the code is.

agencies / freelancers

Dashboards

Dense screens with tables, states, and empty views, which models usually fake.

SaaS / admin

Portfolios

Taste is the product here. The rules keep it consistent across every case study.

designers who code

Internal tools

ops / tooling
